# v0.2.0 — Steel and Flesh

First procedural art pass: faceted tapered swords, forged quillons, wrapped grips, closed helmet and bevor, layered cuirass and fauld, articulated shin armor and sabatons, textured stone courtyard, arched oak gate, banners, static masonry instancing, procedural reflective lighting, layered synthesized steel clash and hit sounds. Five-zone touch, hold/toggle parry, accepted guard geometry and combat rules unchanged. No external model or texture dependencies; Three.js CDN remains. Prior release preserved in archive/v0.1.4-steel-in-motion. 40 logic and geometry tests pass in JS harness; JavaScript parsed. Actual WebGL rendering, appearance, performance and physical iPhone testing not verified. Procedural art, not photorealistic; physical collisions deferred.
